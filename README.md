# Scoundrel Companion

A simple HP tracker for **Scoundrel**, the solo dungeon-crawling card game.

Scoundrel Companion helps you keep track of your health points (HP) while playing, allowing you to focus on navigating the dungeon and surviving its challenges.

## Features

- **HP Tracking:** Keep track of your health points during a game.
- **Lightweight:** The entire application is contained in a single HTML file.
- **No Installation Required:** Use the app directly in your browser.

## How to Use

You can use Scoundrel Companion in either of the following ways:

### Option 1: Open the Website

Visit the hosted app directly through its URL:

**[Scoundrel Companion](https://amwyashar1012.github.io/scoundrel-companion/)**

### Option 2: Download the App

You can download Scoundrel Companion in either of these ways:

- From the Repository: Navigate to the repository's main page, click the Code button near the top, and select Download ZIP.

- From the Releases Page: Open the repository's Releases page, select the latest release, and download the available source code ZIP archive.

Once downloaded, extract the ZIP file and open the HTML file in your preferred web browser.

### Option 3: Clone the Repository

If you have Git installed, run:

```bash
gh repo clone AMwyaShar1012/scoundrel-companion
```
